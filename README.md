# Adivina el Número Secreto

## Descripción

Este proyecto consiste en un juego sencillo desarrollado en Python en el que el usuario debe adivinar un número secreto generado aleatoriamente entre 1 y 100.

El proyecto fue desarrollado como un ejercicio práctico para aplicar prácticas de calidad de software y simular un flujo de trabajo ágil utilizando GitHub.

## Prácticas de calidad aplicadas

### 1. Coding Standards

Se utilizaron herramientas de análisis y formateo de código para mantener un estándar de programación consistente.

* **Black:** utilizado para aplicar un formato automático y uniforme al código.
* **Flake8:** utilizado para detectar errores de estilo y posibles problemas en el código.

Estas herramientas ayudan a mantener el código ordenado, legible y fácil de mantener.

### 2. Pull Request y Code Review

Se creó una rama independiente para realizar una modificación al proyecto y posteriormente se generó un Pull Request hacia la rama `main`.

Antes de integrar los cambios se realizó un Code Review para verificar que la modificación cumpliera con los estándares establecidos.

Esta práctica permite detectar errores antes de integrar los cambios y facilita la colaboración entre los integrantes del proyecto.

## Problemas que se evitan

Las prácticas aplicadas ayudan a evitar problemas como:

* Errores de estilo y formato.
* Código inconsistente o difícil de leer.
* Integración tardía de cambios.
* Errores detectados demasiado tarde.
* Retrabajo durante la integración.

## Relación con lo discutido en clase

Estas prácticas se relacionan con el desarrollo ágil porque permiten integrar cambios pequeños y revisarlos continuamente.

El uso de ramas y Pull Requests ayuda a evitar una integración de último momento o enfoque **"Big Bang"**, donde todos los cambios se integran al final y pueden aparecer numerosos conflictos o errores.

El uso de Coding Standards también reduce el retrabajo, ya que los problemas de formato y calidad pueden detectarse desde etapas tempranas.
